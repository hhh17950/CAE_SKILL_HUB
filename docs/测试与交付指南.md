# 测试与交付指南

## 自动化测试

在项目根目录的 Python 3.10 虚拟环境执行：

```bash
PIP_CONFIG_FILE=/dev/null python -m pip --isolated install --index-url https://pypi.org/simple -r requirements-dev.txt
python -m pip check
python -m pytest -q
python -m ruff check .
python -m ruff format --check .
python -m scripts.export_openapi --check
python -m scripts.check_docs
```

快速测试将等待缩短到 0.01 秒，但启动真实 Python 子进程，不仅 mock 返回值。每项测试使用临时数据库，通过 Alembic CLI 先迁移；应用自身不迁移。

覆盖：参数映射、退出码、超时、取消、任务隔离、鉴权与跨 owner 访问、参数校验、路径和符号链接越界、排队后文件失效、三类日志、缺失/损坏结果、数据库版本检查、显式迁移/回滚、重启恢复及单 Worker 锁。

本轮在 Python 3.10.11 下移除 aiosqlite 后验证 SQLAlchemy 存储、线程隔离、事务取消等待、原子领取与回滚；保留真实 60 秒验收。新增 Compose 配置检查和离线 Swagger 资源、校验和、反向代理前缀、日志隔离测试。Compose 配置测试不需要 Docker 引擎；缺少 Docker CLI/Compose 时会明确跳过。

## 实际 60 秒验收

```bash
CAE_RUN_SLOW_TESTS=1 python -m pytest -q tests/test_runs.py -k sixty
```

保留实际 60 秒等待，期间检查 API 可响应、任务为 running，结束后为 succeeded。默认快速测试跳过此项。

人工按 [对接指南](对接指南.md) 提交任务，先准备已有工程目录，再检查三份日志和自定义输出是否按所传路径生成。Worker 设置 `CAE_TEST_EXIT_CODE=7` 并重启可验证失败；超时设为 1 秒、等待 60 秒可验证 timed_out。验收后恢复默认配置。

## Linux 与真实系统验收

开发主机为 macOS，Python 3.10.11；实现面向 Linux/POSIX，使用 `fcntl.flock`、进程组和信号，不提供 Windows 分支。本机 Docker 未运行，不能将开发机测试当作已完成 Linux 验收。内网 Linux 交付前须重复安装、迁移、快速测试和 60 秒验收，验证进程管理器的停止清理。

双容器检查：按开发指南构建、手动迁移、启动，使用 `/models/part.stp` 提交；执行中 `docker compose restart api` 后应能继续查询原任务，Worker 不被重启。检查模型只读挂载、UID 10001 的数据目录权限、日志持久化、Worker 停止后的 unknown 状态。数据库应为 DELETE 日志模式，Navicat 查看前确认文件及父目录权限，不删除辅助文件。自动测试验证 DELETE 模式下的完整性与并发领取。

离线 Swagger 检查：断开外网后打开 `/docs`，页面资源和 OpenAPI 应来自同一内网服务。自动测试验证 HTTP 资源地址及文件完整性；实际浏览器渲染、反向代理与容器镜像启动仍需部署环境验收。

真实 guie2 另行验收：启动命令、8 个环境变量、数值单位、GUI 会话和许可证、前台等待、日志编码、结果 JSON 及进程树清理。测试脚本不能验证 CAD、网格、材料语义或求解正确性。
